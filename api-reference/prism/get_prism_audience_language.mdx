<Warning>This partial implementation is staged locally and disabled. It has not passed combined production verification.</Warning>

The documented adapters cover YouTube, Instagram and TikTok. Each samples at most five posts and one top-level comment page per post, capped at 50 comments. YouTube uses recent uploads and time-ordered comments. Instagram/TikTok sort the returned creator post window by publication time and retain native comment order. Owner and post identities are checked. Feed omissions and pins can affect these bounded windows; the result is not exhaustive account history. Failed pages remain failures. Instagram reply expansion is explicitly disabled.

`comment_language` separates sampled, counted and abstained comments. Shares use classified comments as the denominator, with up to three verbatim examples and a Wilson 90% interval. A headline share is null when its interval is wider than 0.25. Script heuristics label Hangul, Kana and Thai. A bounded closed-list model judges Latin text and sufficiently contextual Han prose; Han script alone never implies Chinese. Han judgments admit Chinese/Japanese or cannot_tell, with per-comment script eligibility checks. Ambiguous names, mixed, short, oversized or uncertain text abstains. Intervals do not correct for sampling bias, repeated authors or classification error. Text language never establishes a person's location or nationality.

TikTok also has two separate location observations: returned audience-country counts and region fields from one native follower page. The first route costs **26 provider credits**; it reserves 26 units from the existing shared allowance before dispatch. Other SC source reads reserve one unit each. Every YouTube read requires a reservation from the unchanged existing YouTube30 journal; model batches keep the existing Groq100 cap. Source, quota, body and model work receive parent cancellation/deadlines, including injected work that ignores AbortSignal. No allowance is created, reset or enlarged. Counts reflect returned observations, not extrapolated follower populations; missing region fields stay unknown. If the source omits a TikTok comment ID, an opaque per-window observation label is used only for classification.

`divergence` is advisory local policy, not a measurement of commenter geography or verified reference parity. It requires at least 200 classified comments and one geography sample with at least 200 observations plus an untied country mode. Audience counts are preferred; a sufficiently large follower-page region sample is the fallback. A second adequately sampled geography mode that disagrees suppresses the comparison. The language mode must be untied with a configured compatibility entry. Unknown markets, unresolved modes, unavailable evidence or inadequate selected samples produce null. geography_source and geography_rows identify the selected side; both raw geography observations retain independent sample sizes. The method version and comparison status are returned. The country-language table is deliberately bounded and does not infer anyone's residence.

Nonempty observed comment samples cost two SocialQuery credits even if judgment abstains. Observed empty samples cost zero; failure of every selected comment page retains no charge. Source and model work are bounded by one request deadline and cancellation. No live provider calls were used to implement or test these adapters.

Sources: [YouTube comment threads](https://developers.google.com/youtube/v3/docs/commentThreads/list) and the saved [ScrapeCreators OpenAPI](https://docs.scrapecreators.com/openapi.json).
