Partial local implementation; production disabled pending source capacity and combined verification. Supports canonical YouTube and TikTok video URLs with native captions only. Checks 1–12 required talking points and up to 12 forbidden claims against verbatim transcript quotes. Levels are 0 absent, 1 passing mention and 2 explained; visual demonstrations (level 3), descriptions/on-screen disclosure and other platforms are not implemented. Requested disclosure always produces review because transcript marker presence is not contextual compliance proof. Missing transcripts or unavailable/ungrounded model judgments return review with null labels and zero credits. An evaluated report is 15 credits. No AI speech-transcription fallback is enabled. Labels are for human review; automated_decision is false.
