Audits public profile evidence on TikTok, Instagram, YouTube, X, Threads, Bluesky and Truth Social. The default selection is TikTok, Instagram, YouTube and X. Supply a bare handle or canonical supported profile URL. A YouTube channel ID selects YouTube alone; mixed selections with a channel ID are rejected. Other profile URLs retain the default fanout. Matching handles do not verify shared ownership.

Each platform supplies one profile and one bounded post window. `sample` selects a local prefix of 1–25 eligible rows (default 10). Unknown values remain null; explicit empty text and media remain observed zero/false. An empty window does not establish an empty posting history. Returned text is a Unicode-safe prefix of at most 1,000 UTF-8 bytes, with `text_truncated` and the full observed `text_length`. YouTube uses native channel, uploads-playlist and video-detail reads to obtain title, description and view/like/comment statistics. Missing details and live/upcoming records are counted separately. No media is downloaded.

Scores use the published advisory rules in `methodology.score`, versioned as `socialquery-public-handle-window-2.0.0`. `reference_score_v2_compatible` is false. The five component weights are .10/.25/.25/.25/.15; every component is required for each platform score, and every selected platform score is required for the overall mean. Known-only richness inputs renormalize their weights. Unknown evidence never becomes a zero score. Results round to four decimals before thresholds of 70 and 40. Scores do not measure authenticity, unique audience, global activity or calibrated probabilities.

Optional `relevant_to` accepts 1–400 characters. One existing xAI Chat request judges up to 25 already retrieved live post prefixes, selected round-robin across platforms; at least three are required. The judge receives at most 450 UTF-8 bytes per post. A keep label requires an exact quote from that indexed prefix. `domain_relevance.score` is the share kept, not a conclusion about a complete post or a person. The base score and evidence fingerprint do not read the subject or model output. The adjusted score is .7 × base + .3 × topic, rounded before the same thresholds. Insufficient or unavailable judgments remain null with warnings at the same price. Stale posts are not judged.

Transient source errors may recover compatible public evidence from a bounded process-local cache for up to 24 hours. Missing/private or invalid profiles invalidate compatible cached evidence. Monotonic request ordering prevents older in-flight writers from replacing newer cached observations. Case-sensitive YouTube channel IDs remain separate. Global cache consistency and source freshness are unverified. Legs remain in plan order, expose internal dispatch latency and unknown provider cash, and omit speculative post legs after terminal profile failure.
