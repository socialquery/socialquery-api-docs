Implemented locally; disabled until combined verification. Independently collects public GitHub metadata with five open issues and five releases, the first 20 HN search hits with three bounded thread expansions, the first Reddit search page with three top-level comment expansions, and up to five indexed developer-blog snippets. Dates filter HN, the returned Reddit sample, and blog publication; the GitHub dossier remains current. Explicit repo anchors identity; otherwise only a unique exact repository link in observed HN/blog results is accepted. Failed sources remain unknown, confirmed repository 404 is observed absence, and successful empty searches remain empty. The published pulse formula uses four activity flags: a release within 30 days; at least three sampled HN stories or 50 points; at least three sampled Reddit threads or 25 score; at least three sampled blogs. Two active flags yield strong, one steady, none with observed presence cooling, and no presence quiet. A missing requested source leaves pulse null. These labels describe a level heuristic, not a measured temporal trend. Optional existing Groq analysis receives bounded public samples and returns quote-grounded feature requests, complaints and expressed sentiment; counts and top groups are recomputed locally. Flat 20 credits; a strict majority of requested data legs failing settles to 10, exactly half still settles to 20, and all failing refunds the full reservation. Optional analysis failure does not affect data billing. JSON only. Native live payloads, model quality, allowances and production settlement remain pending.
