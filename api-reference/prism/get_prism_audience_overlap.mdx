Supply distinct `handle_a` and `handle_b` TikTok handles. `videos_per_creator` selects up to 10 recent videos from one source page (default 5). Standard depth reads one top-level comment page per video; `depth=deep` reads up to three. This is a bounded sample, not an exhaustive follower or comment collection.

Both public creator identities and their video lists must resolve. Each video must belong to its creator, and each comment must belong to its video. Commenters are deduplicated by stable user ID across videos; the two seed creators are excluded. Shared commenters, exclusive counts and Jaccard are calculated from those sets. Usernames are display metadata, never identity keys.

A creator whose comment sample is unavailable causes failure. An observed empty sample gives null overlap metrics and zero credits. A defined result costs 20 credits, including results with explicitly marked partial comment legs. Failed reads are not treated as empty pages.

`confidence` is `insufficient` for undefined comparisons, `low` for partial samples or fewer than 100 commenters on either side, and otherwise `moderate`. These are versioned heuristics, not calibrated statistical confidence. Commenters overrepresent active fans, source ranking affects selection, and bots are not reliably identified. Observed shared IDs do not make sampled Jaccard a lower bound on full-audience Jaccard.

The response includes per-video page outcomes and `methodology_version=commenter-sample-1.0.0`. New work stops at the shared deadline or a provider-capacity failure. Native cursors are never replaced with guessed row offsets.
