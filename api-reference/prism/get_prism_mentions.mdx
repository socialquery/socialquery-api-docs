<Note>This adapter is staged locally and remains disabled until combined verification.</Note>

Disabled local first-page mention report pending the combined audit. Supply exactly one handle, URL path prefix or name. X and Reddit searches use literal/native handle or link evidence; Instagram resolves a public account and reads its tagged tab; web requires an observed link in the returned page content. Facebook, Threads and TikTok selections are accepted but not searched. One credit when any searched source completes, even empty; complete source failure is refunded. Name judgments use exact quotes and a 0.5 relevance threshold; unavailable judgments retain explicitly unjudged search candidates. URL first_seen is only the earliest dated returned match. Self-account exclusion works in handle mode. Unknown dates remain visible. No exhaustive index, ownership inference or arbitrary URL fetching.
