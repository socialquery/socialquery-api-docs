Combines three documented trend windows without treating their populations as equivalent. Supply an uppercase two-letter country_code, period 7 or 30 (default 7), and limit 1–10 (default 10). Google Trending Now always covers seven days, including period=30 requests. Its reported episode start is not first-ever public interest. Source positions, repeated query episodes, null values and explicit zero counters are retained.

popular_posts contains TikTok Creative Center popular-video observations for US, JP, VN, TH and ID. These are chart posts, not the local feed and not verified organic breakouts. Period views and lifetime views remain separate; the source may include paid/branded content. breakout_posts and rising_sounds remain null because these sources do not establish author-median ratios, registration-country identity or sound freshness/returning status. No related chart is represented as those unavailable signals.

rising_hashtags contains the overall published three-row hashtag chart for 27 documented markets. limit selects a prefix without refill. Relative-index change is last minus first curve point; percent change is null when the first point is zero. first_nonzero_window_date means only the first positive point in that delivered curve, never first-ever interest. Native ranks, posts, views, curve dates and top creators are source observations. No global cross-source rank, independent demand calibration, complete history or model interpretation is claimed.

sources records each section's ok, unavailable or not_supported state, original capture time, internal dispatch latency and known/unknown source cash. A failed section stays null, not a successful empty array. All-source failure returns an unbilled error. Partial success and explicit empty Google observations cost the same fixed 30 credits. Fifteen-minute exact-plan process-local public cache hits cost zero; only captures with no failed supported source are cached, up to 100 keys. There is no history, stale-if-error recovery or global cache guarantee. Immutable replay is free. Caller cancellation (499) and the global deadline (504) fully refund.

The global configured window is 55 seconds and all three sources start concurrently. Google rate, reservation, account, transport/body and projection work is bounded; runtime Google reads require the existing Free Plan with no extra credits before one search. TikTok reads use pinned Actors with limited permissions, no restart/enrichment/media download, full existing-pool reservation of eight cents for video and one cent for hashtags. The shared Apify 500-cent cap and existing Google zero/unallocated journal retain their limits. Independent HMAC request/evidence/time receipts are reprojected at settlement. These bounds are not measured latency guarantees. Disabled pending native source usability, eligible sustainable capacity and hosted API/client/ledger acceptance.
