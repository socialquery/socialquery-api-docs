<Note>This adapter remains partial and disabled. Production remains on the saved release 2026-10-11.120; unavailable requests return HTTP 503 without consuming credits. The behavior below is implemented and verified locally, pending full contract acceptance.</Note>

On the first page, supply `query` and `location`. `country=us` (default) or `country=gb` explicitly selects the source index; country is never guessed from location. One pinned source run collects at most twenty jobs. Each response scans at most ten collected rows. Optional day/week dates, remote-only and employment selections filter each scanned page without refilling it. Employment types accept `fulltime;contractor` and legacy comma-separated FULLTIME/PARTTIME/CONTRACTOR/INTERN. `temporary` has no verified source equivalent and returns 422 before source reservation.

When `next_cursor` is present, pass it as `cursor` to read the next page of the original source snapshot. Query, location and filters can be omitted; supplied values must match the original search. The encrypted cursor binds the snapshot to the user and API key and expires five minutes after collection. A missing, expired or inconsistent snapshot fails without launching another Actor. This is continuation within a saved twenty-job window, not native Bing pagination, exhaustive search or support for deeper pages. `total` remains null and `complete` remains false.

The first page holds and settles ten credits for a validated nonempty source window, including a locally filtered empty page. Snapshot continuation holds and settles zero credits, accepts `X-Max-Credits: 0`, makes no additional source call or source quota reservation, and does not refresh the snapshot lifetime. Raw empty/error/inconsistent source windows and snapshot write failures fail unbilled. A failed source run still retains its upstream safety reservation. Empty output does not establish no matches, a closed role or not-found absence.

Job IDs and raw Bing UIDs remain distinct, and native positions remain separate from positions within a page. Operation/query traces, ordered identities, publisher associations and ISO/epoch date aliases must agree. Midnight UTC may encode only a date; exact-time precision remains unknown. Day/week filtering retains possible date overlap and unknown dates. Location text and observed country fields do not prove geographic completeness. Remote and employment flags are source observations.

Search lists omit descriptions and apply links from both items and independent receipts; use the exact-id detail route for those observations. A served posting does not prove that the role remains open, and no salary, logo, verified direct-apply or complete-description claim is supplied.

A first-page run is capped at $0.10, 50 seconds, 512 MiB and twenty rows. One 55-second deadline bounds reservation, transport, body, snapshot storage and projection. Source bodies are limited to 2 MiB; snapshots to 256 KiB. The shared non-refilling Apify safety journal has a $5 ceiling and reserves the full ten-cent run cap before dispatch; no automatic refill or top-up occurs. Source usage is an estimate, not a final invoice. Query-free searches, temporary employment, native/deep continuation, broader location/date/empty parity and combined deployed acceptance remain gaps. The separate locally complete detail gate remains enabled pending deployment.
