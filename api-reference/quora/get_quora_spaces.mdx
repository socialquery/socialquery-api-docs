Search public Quora Spaces by keyword `query`. `limit` accepts 1–10 (default 10); `time` accepts `all` (default), `hour`, `day`, `week`, `month` and `year`, forwarded to the native search freshness control. This does not establish Space creation or latest activity. Direct URL targets and pagination are unsupported.

Each item contains the native Tribe ID, name, URL, nullable description, member count, follower count and icon metadata. The numeric Tribe ID and opaque GID must agree, as must duplicate source name/link/description/member/follower/icon fields and query/type/time traces. Native Space search URLs use `type=tribe`. Members and followers remain separate observations; neither is calculated from the other, and missing values stay null. Default icons are marked. Icon-path IDs are metadata rather than Space identity; no icon is fetched or certified available. Source counts, relevance and descriptions are not independently verified.

A nonempty source window settles five customer credits from a five-credit hold. A completed empty window settles zero and refunds the hold without proving a Space absent from Quora. Source failure, inconsistent rows, duplicate identities and overflow cannot settle a successful charge. Confirmed failures, cancellation (499) and deadline expiry (504) fully refund; source authentication/quota errors return 503. Immutable idempotent replay performs no source work and adds no charge.

One pinned Apify `fatihtahta/quora-scraper` build `0.8.14` run handles the request, with 512 MiB, a 40-second Actor timeout and a 45-second active window covering reservation, transport/body reads and projection. Source and output limits are 2 MiB each. No automatic retry, detail enrichment or asset fetch occurs. Already accepted remote work may finish under its original cap after local cancellation.

The provider requires a **$1 maximum-charge setting** even for small runs. Requests save at most ten records, with published $0.00099 output-record pricing. Only exact pinned single-keyword Profile/Topic/Space/Post plans qualify for the exception under their existing row, memory, byte and deadline bounds; other Actor caps remain unchanged. Reported provider usage is an incomplete estimate, separate from customer credits. The runtime allowance stays zero/unallocated.

Eight native diagnostics covered the ten-result window and all six filter settings. The hour-filter query and deliberate no-match query completed with empty datasets; other windows supplied 20 row observations, including missing descriptions and generic default icons. Original captures and selected redacted fixtures pass projection, schema and canonical settlement. Authenticated API, both MCP clients, Python and disposable SQL use simulated source transport and Redis. Shared capacity, real Redis and combined hosted acceptance remain separate from these checks. `complete=false`, `total=null` and `next_cursor=null` describe a bounded search window.
