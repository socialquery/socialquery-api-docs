title: "Facebook Search Posts"
openapi: "GET /facebook/search/posts"
---

Implemented locally from the pinned 0.0.337 Facebook Search input/dataset schemas and offline checks; disabled pending native quality, existing shared capacity and hosted acceptance. Supported raw post/reel observations replace unavailable reference promises.

Use query, limit=1–7 (default 7), optional free-text location, optional include=author,media and sort_by=source/newest/oldest/likes. One native source window only; max_pages=1 is accepted. No public cursor, numeric location-ID mapping, exhaustive history or global newest/relevance promise. Location maps to native locations but is not verified geography. Without location, a provided source search URL must corroborate the literal query. With location, retain that URL as an observation without guessing native query composition or claiming an independent query/location echo. Source preserves dataset order; other sorts rank only delivered rows, unknowns last with stable native ties. Likes use actual reactionLikeCount, never total reactions.

Inclusive since/until or start_date/end_date UTC calendar-day filters apply locally after collection; aliases must agree. Unknown timestamps are excluded and counted only when dates apply. max_age_days=1–3650 sets a local lower UTC date bound, N calendar days before the source capture date, combined with any later explicit lower bound. Canonical receipts recompute relative dates from the fixed capture time. No refill or historical traversal.

include=author selects documented user/pageName fields. User, flat author and page-name IDs must corroborate when present; URLs with embedded IDs must agree. Preserve distinct source page labels, use explicit author basis and never infer verification, real-person identity or a profile lookup. Without include, existing flat author observations remain available. include=media selects at most 20 documented attachment URLs/thumbnails/type/OCR text plus available reel thumbnail/duration/dimensions; public Facebook links must identify the same post, CDN links must use allowed HTTPS hosts. Unknown type remains unknown, thumbnails do not prove full-resolution media or complete galleries, temporary URLs are inert and neither fetched nor playback-verified. Private/untyped extensions and unsupported nested fields are omitted. Missing values remain null.

Nonempty validated source windows cost one credit even when local dates remove all rows; native empty zero does not prove absence. Exact duplicates collapse; conflicting identities, malformed timestamps or unsafe media fail unbilled. Same one pinned Actor, $0.10 charge ceiling, 40-second Actor/45-second total and 2 MiB source/output bounds. Parent cancellation and rate-check/reservation/transport/body/cleanup/projection share an active deadline; errors and 499/504 refund, immutable replay free. Custom AI relevance/fit is unavailable; judgments accepts off only and the default contract is raw unlabelled observations. All gates false and existing journal zero; no allocation or activation.
