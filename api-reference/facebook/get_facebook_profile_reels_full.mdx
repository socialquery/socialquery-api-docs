Collects public reels, then adds counts observed on matching reel permalinks. Grid views remain separately identified as approximate; detail views can be null or differ from the grid. Reserve 5 credits per planned page (ceil(limit/10), maximum 25); unused pages are refunded. Each nonempty page costs 5 if at least one detail lookup succeeds, otherwise 1. Empty pages cost zero. Detail failures retain list values and report engagement_partial. A signed one-hour cursor binds the profile and both source cursor fields. A partially returned page is re-read with its consumed prefix checked, avoiding silent row loss; page changes return CURSOR_STALE. Media URLs are not fetched or certified playable.

A native Meta sample resolved one reel through two source calls. Runtime source calls reserve the existing shared 100-request ScrapeCreators ceiling; it is not refilled automatically. Reservation, transport, body reading and cleanup respect cancellation/deadlines; failures refund customer holds. Local native-fixture API tests validate all three response specifications and both MCP/Python clients. Broader native cursor/empty/profile behavior is not inferred from this single sample.
