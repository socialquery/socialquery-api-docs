Search the public web index for Facebook groups by `query`. A page contains at most ten indexed hits, deduplicated to group URLs in source order. `author.ext.search_hit` retains the exact evidence URL, title, snippet and whether it matched a group page or a post inside one. A post title never becomes a group name. Group-page names are index display labels until a detail lookup supplies the native name. Unknown member counts, descriptions, creation dates and privacy stay null.

Use `include=details` to request public About-page enrichment for each returned group. It fills known member count, description, creation date, native numeric ID, privacy/visibility and activity. A numeric response alone cannot corroborate a vanity alias; that lookup remains unfilled and refunded. Group URLs remain usable by the group and group-post operations. Indexed discovery does not prove the group is readable; inspect privacy before attempting posts. Numeric and vanity aliases may recur across pages.

Plain discovery holds one credit. Details holds eleven: one for a nonempty group window plus one per usable fresh enrichment. Cached, failed, deferred and empty-field lookups add no enrichment charge. Empty discovery refunds the base credit; response-cache hits are free. `hydration` reports attempted lookups, cache hits, outcomes, credits and elapsed time. Source cost stays explicitly unknown. No administrator/member identities or generic AI labels are returned.

Return `next_cursor` verbatim with the same query, include, judgment, topic and threshold controls, without page. Cursors expire after one hour; paging stops at page 100, with truncation explicit. Native index continuation is checked, never followed as an arbitrary URL. Details use three workers and a twelve-second deadline; at most ten lookups are attempted. Overall collection is bounded to fifty seconds and 2 MiB source/response bodies.

Parent cancellation covers source reservation, rate checks, fetch/body reads, optional cache work and hydration. It returns `499` with a full collection refund; source/overall deadline failure returns `504`. Individual failed hydration remains uncharged while valid discovery can still return. Cleanup never waits indefinitely, and late allowance acknowledgments cannot start another source request. Already accepted upstream work may still consume its reserved source allowance.

By default, each row carries `computed.relevance` against the query. `relevance=score` requests this explicitly; `relevance=filter` also removes judged rows below `relevance_threshold` (default `0.5`, range zero to one, up to six decimal places). Source order and native pagination stay unchanged, with no replacement fetch for dropped rows. Unjudged and `sense=unclear` rows are always retained. The response reports scored, cached, unjudged and dropped counts and IDs. These are uncalibrated judgments over bounded public text, not verified group facts, membership, completeness or measured probabilities.

`judgments=off` or `label=none` omits relevance keys and makes no inference call. It cannot be combined with explicit relevance. Generic category/other labels and `fit` remain unsupported and reject before source work.

With explicit relevance, `relevant_to` supplies a different topic of one to 200 characters. It adds a one-credit hold, for a maximum of twelve credits with details. Only fresh successful judgments are charged, at one credit per started 25 rows; cached, short, failed or unjudged rows add zero. Query-topic relevance is free. Filtering every row does not refund a successfully read nonempty source window. Exact page-cache hits and idempotent replays remain free.

Judgment caches bind the topic, group key, actual bounded text, model and methodology version. They expire after one hour; no cached judgment is reused for changed text or another topic. Model IDs, numeric ranges and exact same-item quotation evidence are validated before filtering or billing. Invalid, incomplete or unavailable model output preserves all unjudged rows and refunds the extra judgment hold. Parent cancellation during inference or its reservation refunds the entire request, including the source window.
