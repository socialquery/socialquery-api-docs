<Note>Staged locally and disabled. Source, contract and capacity checks remain open. Unavailable calls return HTTP 503 without consuming credits.</Note>

Partial local typed adapter, disabled pending native source, filter semantics, capacity and combined verification. Reads one people-search page for query, first_name, last_name, title, school, current_company, industry and profile_language (en/es/fr/pt/other). Unsupported past_company, geocode_location, service_category and follower_of return 422; they are never ignored or converted to an exclusion filter. include=profile hydrates a core public-profile projection for each returned member and fails the request on any failed or mismatched hydration. No complete career history or verified employment claim. A validated page, including a native empty page, costs 10 credits; source/enrichment failure receives the normal full refund.

Pagination uses page 1–100, limit 1–10 and a returned HMAC-authenticated one-hour cursor bound to the operation, identity, filters, page size and hydration choice. Native page-size clamping is explicit. At page 100, source_has_more can be true while pagination_truncated=true and next_cursor=null. Source errors are never converted to empty results. Requests use a 55-second total deadline, 1 MiB per response and at most 12 calls. Provider capacity remains unallocated.
