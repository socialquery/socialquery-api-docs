<Note>Implemented locally and disabled until combined source, capacity and settlement verification. Unavailable requests return HTTP 503 without consuming credits.</Note>

Return public career positions and the skills attached to each role from a canonical LinkedIn `/in/` URL. Profile identity, company identifiers, role fields and calendar precision are validated. The pinned provider runs in explicit no-email mode and the response omits unrelated profile data.

Missing role skills remain `null`; an explicitly empty list remains `[]`. Profile-wide skills are never copied to a role. Unknown calendar days, logos and whether LinkedIn helped obtain a job stay null. A company search-placeholder link is unresolved, not a company identity. This is the returned public snapshot, not a guarantee of complete history, endorsement or skill verification.

A validated response costs five credits. The provider is capped to one profile, forty seconds, two MiB and a $0.02 run ceiling. Its verification journal remains unallocated; there has been no source execution. Provider failures receive the normal full refund.

Raw Unicode profile identifiers and their canonical uppercase UTF-8 percent encoding now identify the same member across caller input, source URL and query echoes. Identifiers allow letters, combining marks, numbers, hyphens and underscores, with at most 100 decoded code points. Encoded ASCII, partial/mixed encoding, invalid UTF-8, separators, controls and symbols reject before spending. Equivalent host/trailing-slash variants also canonicalize. Case and Unicode composition remain distinct: no case-folding or Unicode normalization is applied. Declared source usernames retain their original accepted spelling. Exact request replays are free; changing wire parameters under the same idempotency key still conflicts, even for equivalent URLs.

Two native accented-name lookups completed in one no-email Actor run capped at $0.02. One later read-only check reported **$0.008**, two profile events and zero email events. Both unmodified rows pass offline complete/all/position projection and their observed interest tabs, using raw and encoded inputs; source order is restored in a deduplicated batch. No native Groups tab was present. Other identity forms and failure variants use synthetic contract tests; these do not establish maximum-size native capacity or production readiness.
