<Note>This partial comment-preview adapter is staged locally and disabled. One native article read returned five comments against seventeen reported. Production remains 2026-10-11.120 pending combined verification.</Note>

Supply one canonical HTTPS LinkedIn Pulse article `url`, with optional `page=1`. Bare/www hosts and a trailing slash normalize. Query strings, fragments, credentials, explicit ports, escaped/dot paths and non-Pulse URLs reject. Later pages, cursor, since/until and unknown parameters reject before a credit hold or source reservation. The source supplies no comment timestamps or paging token, so those capabilities are not simulated.

One ScrapeCreators capacity read must observe at least two existing credits before one fixed-host `/v1/linkedin/post` request. The native article URL must match the request. Every source comment is validated, up to one hundred, before at most twenty are displayed in source emission order. Source positions are neither comment IDs nor certified rank. Repeated author/text rows remain separate because stable comment identities are unavailable.

Native commenter names, text and public LinkedIn profile/company URLs are observations. Localized two-letter LinkedIn profile hosts normalize to www; URLs are not followed. Stable commenter IDs/usernames, comment IDs/permalinks/post IDs, timestamps, engagement, flags, replies and language remain null. No slug-derived identity, deleted-state guess or article timestamp substitution is made. Reported article comment count stays separate from preview size; `total=null`, `complete=false`, `source_has_more=null` and `next_cursor=null`. A truncated preview does not imply an accessible next page. Article body/title/author, related articles, media, contacts, account balances, authentication and arbitrary enrichment are excluded from output and independent source receipts. No model request is made.

The existing five-credit hold is unchanged. A nonempty source preview settles five. Only an explicit zero native count plus empty preview can settle zero locally, without proving global absence. Empty preview with positive or unknown count fails without a net customer charge. Native zero/negative/refund acceptance and exact wider field/pagination contracts remain unverified. Current external reference pricing differs; this local addition preserves SocialQuery's saved five-credit price.

Source credit charges remain observations rather than a dollar invoice. The native article read reported one credit; its capacity read omitted a charge, leaving the combined total unknown with a one-credit floor inside the two-credit diagnostic cap. Unknown usage is never labeled free. Private balance observations are not API receipt fields, current account capacity guarantees or sustainable allowance. Runtime credential stays only in the header at api.scrapecreators.com; no alternate provider or link fetch.

A thirty-five-second shared deadline includes an actively timed reservation, both source reads and projection. Each source transport caps at fifteen seconds and 2 MiB; output caps at 4 MiB. Independent canonical receipts expire after ten minutes and reproject source observations and usage at settlement. There is no retry, refilling, model call, article/commenter hydration or cache. Rate two requests/minute, own journal zero/unallocated, all three gates false. Full fields, comments paging/date filtering, broader native source/empty/error/refund, sustained capacity and combined live REST/MCP/Python/ledger acceptance remain open.
