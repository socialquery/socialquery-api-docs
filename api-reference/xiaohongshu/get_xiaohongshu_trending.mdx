Returns one ranked hot-board snapshot. `limit` accepts 1–20 topics and defaults to 10. Smaller limits select the ranked prefix of that source snapshot. There are no date/search filters, cursor, next page or refill. A later call can observe a changed board.

Each returned topic includes its source-list id, title, contiguous source rank, heat value/text, label and source scrape time. Heat values are source observations; exact search volume, unique viewers, native board update time and independently verified current-board freshness remain unknown. This bounded snapshot does not claim to enumerate the entire board. Covers and unrelated source fields are omitted and never fetched.

The request holds `limit × 5` credits: 50 by default and at most 100. Settlement charges five credits per topic returned and refunds unused holds. The source minimum of five rows never increases the customer limit or adds customer charges. A raw empty/error dataset, duplicate topic id, inconsistent rank/list/heat or stale source row fails unbilled; an unavailable source does not establish an empty board. Successful idempotent replays preserve the original payload and cost zero additional credits.

The pinned source run is bounded at $0.08, 50 seconds, 256 MiB, a 55-second common deadline and 2-MiB source bodies. Its cost estimate remains separate from customer credits and final invoices. No retry or refill starts another run.
