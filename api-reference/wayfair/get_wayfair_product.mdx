title: "Wayfair Product"
openapi: "GET /wayfair/product"
---

Implemented locally from the public axiomworks Wayfair build 1.0.15 documentation and offline checks. Disabled pending native quality, sustainable existing capacity and hosted acceptance. The historical blocked/ambiguous build 1.0.7 probes are not acceptance for this build.

Supported stores are US/USD, CA/CAD and GB/GBP. Search takes a query and one source window (items_per_page=24 or 48, default 48; page=1 only). No public continuation, exhaustive inventory or global newest ordering. sort_by=relevance preserves source positions without certified relevance; price_low, price_high and top_rated sort only the delivered window, with unknown values last and stable native ties. Prices use store currency. Optional min_price, max_price, min_rating, only_on_sale and include_sponsored map to documented native controls and are checked locally. Optional in_stock=true/false matches only known IN_STOCK/OUT_OF_STOCK labels. color matches the literal selected option named Color or Colour, case-insensitively; it does not search every variant or infer material color. only_on_sale=true requires known list price above current price. include_sponsored=false retains only explicitly nonsponsored rows. Required unknown values are excluded; filtering never refills the window. Source filter requests are not independent quality evidence.

Product detail accepts a SKU. It projects public specifications, dimensions, description, one main image and the shown variant's options/ID/URL. Variant URLs must corroborate product SKU and piid. Optional brand links stay on the selected store. Full gallery and variant inventories, manufacturer, exact review-count scope, destination delivery dates, return policies and variant-specific price ownership remain unknown. Source URLs and media are inert metadata and are not fetched separately.

Each nonempty validated source window costs five credits, including locally filtered empty results. Ambiguous empty or malformed source responses fail unbilled; the known source can return no rows when blocked, so emptiness does not prove no products. One pinned Actor, unchanged $0.25 Actor charge ceiling, 40-second source/45-second total window, 2 MiB source/4 MiB output limits. Platform and residential-proxy usage can be billed separately and require capacity qualification; the Actor charge ceiling is not a certified total invoice bound. Existing zero journal and disabled gates remain unchanged. Parent cancellation, rate-limit/reservation waits, transport/body/cleanup and projection share an active deadline; errors and 499/504 failures refund, immutable replay is free. Already accepted remote work can still consume its original charge ceiling.
